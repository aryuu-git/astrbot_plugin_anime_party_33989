# 动画派对 · Emoji 猜动画

AstrBot 插件 **astrbot_plugin_anime_party_33989**，版本0.1.2。

自带30道题（12简单 / 12普通 / 6困难），用Emoji猜动画，支持三层提示、别名判题、难度切换、暂停、限时揭晓与重启续局。无需模型或额外Python依赖即可玩。

内置题面默认三行、每行六个Emoji，按角色/舞台/情节组合线索；题目标题独占一行。每行用空格分隔完整Emoji，避免拆开组合符号。自定义题包仍兼容单行格式。

AI主持是可选的短引子，复用AstrBot现有模型与当前会话人格；答案、提示和游戏进度始终由程序确定。

## 安装与首次配置

适用 AstrBot >=4.28.0,<5，Python >=3.11；首版支持声明为OneBot V11（aiocqhttp）。推荐在当前AstrBot发行版使用。

1. 在插件管理中通过[GitHub仓库](https://github.com/aryuu-git/astrbot_plugin_anime_party_33989)安装，或使用发布ZIP；也可把插件目录放入 `data/plugins/`。
2. 打开插件配置，将 `/sid` 获取的完整会话标识加入 `allowed_sessions`；群聊和私聊分别填写。**默认空列表，不响应任何会话。**
3. 保持 `question_source=builtin`，保存并确认插件加载成功。
4. 在已允许的会话发 `/猜动画 开始`。

此插件自己的允许列表不替代AstrBot全局白名单；两者都应允许目标会话。

## 使用

| 消息 | 效果 |
| --- | --- |
| `/猜动画` 或 `/猜动画 帮助` | 查看帮助 |
| `/猜动画 开始` | 开始一题，默认普通难度 |
| `我猜 命运石之门` | 显式猜测；也可 `/猜动画 我猜 命运石之门` |
| 直接发送题库作品名或别名 | 进行中判题；不在题库的猜测请加“我猜” |
| `/猜动画 提示` | 逐层获得最多三条提示 |
| `/猜动画 答案` | 揭晓并结束本题 |
| `/猜动画 下一题` | 换题 |
| `/猜动画 难度 简单` | 切换简单并开始新题；也支持普通、困难 |
| `/猜动画 暂停` | 停止当前题目 |
| `/猜动画 状态` | 查看当前Emoji与已用提示数量，不暴露答案 |
| `/猜动画 清空` | 管理员清空当前会话游戏状态 |

普通聊天不作为错答。活动题目中默认可直接说“提示”“提示一下”“答案”“暂停”“下一题”，无需重复输入指令前缀；游戏外不会截取这些短语。可通过 `enable_shortcuts=false` 关闭。0.1.0升级用户的既有false配置会保留，需手动开启。只有启动命令才能在游戏外开局，“来一个”不会自行开启游戏。

## AI主持与共存

`ai_expression=true` 后使用当前会话模型，也可指定 `provider_id`。沿用会话绑定/当前对话的人格；插件不携带固定角色、不单独存API Key、不请求聊天历史。

模型只收到事件类型和提示序号，不会收到当前题目的答案、线索或玩家原始输入。模型返回的短引子经检查后附加到固定游戏文案；关闭、超时或故障时使用原文案。

已处理的游戏消息会停止后续事件处理，避免普通聊天或主动接话再次回复；没有处理的聊天会放行。与依赖相同事件的其他插件共用时应做实际验收，特别是优先级更高的监听器。

## 数据与题包

运行数据仅保存在 AstrBot 插件数据目录 `plugin_data/astrbot_plugin_anime_party_33989/`。SQLite保存游戏状态、近期题目和有限消息ID去重记录，不保存聊天正文或玩家姓名，不包含排行榜。

游戏限时默认15分钟，每30秒检查并尝试揭晓。断线或发送失败可能影响通知；状态提交和外部平台送达不是一个原子操作，不承诺消息恰好送达一次。

自定义题包见 [题包格式](docs/question-packs.md)，实现与维护见 [架构](docs/architecture.md)，发布状态和验收见 [发布说明](docs/release.md)。
