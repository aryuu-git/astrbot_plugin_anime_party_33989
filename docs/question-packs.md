# 动态生成规则

0.2.0移除所有内置题和固定题包模式；不再读取question_source、自定义固定题文件或旧版game.db。

出题分为三步：模型提出真实动画标准名称，Bangumi公开API按标准名称核对类型与内容范围并读取简介，再由独立模型调用生成rows、三层hints与explanation。

rows是长度分别5、7、5的三个数组，每格是一个完整Emoji。结构、数量、非Emoji格子或片名泄露不合格时最多重新生成一次；仍失败则明确报错。不会使用旧题补位，也不会只截断多余图标伪装达标。

标准中文名与原名作为确定性答案别名；不依赖聊天模型自由判题。每道生成题有独立内部ID，Bangumi条目ID另存，避免同一作品的新谜面覆盖其他会话的进行中题目。

缓存用于恢复和避重，不等于预置题库。来源仅核对作品身份及提供参考，不能保证每条生成线索都绝对准确。
