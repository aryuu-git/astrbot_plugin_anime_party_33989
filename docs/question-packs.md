# 自定义题包

内置题包从0.1.2起使用三行Emoji；自定义 `emoji` 字段可用JSON转义 `\n` 分行，推荐3至4行、每行6至8个以空格分隔的完整Emoji。下面的单行示例仍兼容。

在AstrBot插件数据目录中放置 `custom_questions.json`，配置 `question_source=custom` 使用纯自定义包，或 `merged` 合并内置包。同一subject_id由自定义条目覆盖；单个题包内不允许重复ID。

```json
[
  {
    "subject_id": 10380,
    "title": "命运石之门",
    "aliases": ["STEINS;GATE", "石头门"],
    "emoji": "⌚🍌📱⚡",
    "difficulty": "easy",
    "hints": ["故事与时间旅行有关。", "主要舞台是秋叶原。", "关键装置与微波炉有关。"],
    "explanation": "实验室成员意外发现了向过去发送信息的方法。"
  }
]
```

支持easy/normal/hard，必须正好三条非空提示，subject_id为正整数。最多5000题、文件不超过5MiB。模板并非在线校验，导入者负责准确性、内容范围和来源说明。

没有所选难度的题目时会从现有题目中挑选。近期避重耗尽后允许重用；同难度存在多题时避免立即重复上一题。

这是管理员管理文件的题包导入方式，首版不提供群文件自动导入或AI自动生成事实题。更换题包后重载插件；如果活动题目已被移除，会恢复为空闲状态。建议先暂停游戏再换包。
